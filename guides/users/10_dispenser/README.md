## 🌅 1 · Morning Check — 08:30 AM / صبح کی جانچ

Tick each box when completed. *(Dashed terms = buttons/tabs you will see on the screen)*

- [ ] **Log in. Check that the pool says `jalalpur_jattan`.**  
  *(لاگ ان کریں — دیکھیں کہ پول `jalalpur_jattan` ہے)*
- [ ] **Open the `[Near Expiry]` tab. Tell the Doctor about any medicine that expires in 90 days or less.**  
  *(Near Expiry ٹیب کھولیں۔ جو دوائی 90 دن یا کم میں ایکسپائر ہو رہی ہو وہ ڈاکٹر کو بتائیں)*
- [ ] **Open the `[Low Stock]` tab. Ask for supplies for any item with less than 20 units.**  
  *(Low Stock ٹیب کھولیں۔ جس دوائی کے 20 سے کم یونٹ ہوں اس کا سامان منگوائیں)*
- [ ] **Scan 1 box with the barcode reader to test it.**  
  *(بارکوڈ ریڈر ٹیسٹ کرنے کے لیے ایک ڈبہ اسکین کریں)*

---

## ☀️ 2 · While the Clinic is Open (OPD) / او پی ڈی کے دوران

1. **Patient gives you a token number. Open their prescription on the screen.**  
   *(مریض ٹوکن نمبر دے گا۔ اسکرین پر اس کا نسخہ کھولیں)*
2. **Compare batch numbers. The batch on the screen must be the same as the batch printed on the box in your hand.**  
   *(اسکرین پر آنے والا بیچ نمبر اور ڈبے پر چھپا بیچ نمبر آپس میں ملائیں)*
3. **Give the medicine. Explain how to take it (how many, how often).**  
   *(دوائی دیں اور بتائیں کہ کتنی اور کب کھانی ہے)*
4. **New delivery arrived? Switch on `[Express Scan Mode]` and scan every carton.**  
   *(نئی دوائی آئے تو Express Scan Mode آن کریں اور ہر کارٹن اسکین کریں)*

> [!CAUTION]
> **STOP — Batch does not match?**  
> Do **not** hand over the medicine. Ask the Doctor or Branch Manager first.  
> *(رک جائیں — بیچ نہیں ملتا؟ دوائی نہ دیں۔ پہلے ڈاکٹر یا برانچ مینیجر سے پوچھیں)*

---

## ⚖️ The One Rule: Oldest Expiry Goes First / پہلا اصول: جس کی میعاد پہلے ختم، وہ پہلے

This pharmaceutical standard is called **FEFO** (First-Expiry-First-Out):

```
┌───────────────────────────────────────┐            ┌───────────────────────────────────────┐
│           Batch BAT-P1-2025           │            │           Batch BAT-P2-2026           │
│       Expires 2027-04-01 · 120 tabs   │    ───>    │       Expires 2028-01-01 · 300 tabs   │
│            GIVE THIS FIRST            │            │       LOCKED UNTIL #1 IS FINISHED     │
└───────────────────────────────────────┘            └───────────────────────────────────────┘
```
> جس بیچ کی میعاد پہلے ختم ہو رہی ہے سسٹم وہی دکھاتا ہے۔ دوسرا بیچ اس کے ختم ہونے تک بند رہتا ہے۔

---

## 🌇 3 · Closing Check — 04:30 PM / شام کی جانچ

Complete these steps before leaving the dispensary desk:

- [ ] **Open `[Stock Check]`. Count at least 5 different shelves by hand and type the numbers in.**  
  *(Stock Check کھولیں۔ کم از کم 5 مختلف الماریاں ہاتھ سے گن کر نمبر درج کریں)*
- [ ] **Open `[Activity Log]`. Make sure every movement (in and out) is explained.**  
  *(Activity Log کھولیں۔ دیکھیں کہ ہر آمد و خرچ کا حساب پورا ہے)*
- [ ] **Make sure every `[edit request]` has been reviewed by the Doctor or Branch Manager.**  
  *(یقینی بنائیں کہ ہر ایڈٹ درخواست ڈاکٹر یا برانچ مینیجر دیکھ چکا ہے)*

| :--- | :--- |
| • **Search medicines · Add stock**<br>*(دوائی تلاش کریں، اسٹاک شامل کریں)* | • **Change a medicine name or formula yourself**<br>*(نام یا فارمولا خود نہیں بدل سکتے — پہلے `Pending Requests` میں منظوری ہوگی)* |
| • **Give medicine against a token**<br>*(ٹوکن پر دوائی دیں)* | • **Approve edit requests**<br>*(درخواست منظور نہیں کر سکتے)* |
| • **Count shelves**<br>*(شیلف کی گنتی کریں)* | • **Wipe a stock pool**<br>*(اسٹاک پول صاف نہیں کر سکتے)* |
| • **Ask for a change with `[Edit]`**<br>*(تبدیلی کی درخواست دیں)* | |

## 📖 Words You Will See / اہم الفاظ

| Screen Word | What It Means | اردو مفہوم |
| :--- | :--- | :--- |
| **FEFO** | First Expiry, First Out — oldest expiry date is used first. | *جو پہلے ایکسپائر ہو وہ پہلے دیں* |
| **Batch** | One delivery lot, printed on the box (e.g. `BAT-P1-2025`). | *ایک کھیپ، ڈبے پر لکھی ہوتی ہے* |
| **Token** | Patient's queue number for today's clinical visit. | *مریض کا آج کا نمبر* |
| **Reserved** | Set aside for a patient by the Doctor — nobody else can give it. | *ڈاکٹر نے مریض کے لیے الگ کر دی* |
| **Pool** | The isolated stock list for one facility (branch or camp). | *ایک جگہ کا اسٹاک* |
| **Requisition** | A request sent to central warehouse for more supplies. | *سامان منگوانے کی درخواست* |
